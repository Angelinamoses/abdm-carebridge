# Synthetic data

**All files in this folder are synthetically generated. None of the records here represent real people, real ABHA IDs, real facilities, or real patient histories.**

Generated by:
- `src/fhir/generate_mock_resources.py` → `synthetic_patient_bundles.json`
- `src/simulation/journey_simulator.py` → `journey_simulation_results.json`

These files are regenerated each time the scripts are run (random seed not fixed by default — set `random.seed()` in the scripts if you need reproducible output for a specific analysis).

## Why synthetic data

This project studies a structural, architectural question (does ABDM's design hold up for a highly mobile population?) rather than an empirical adoption question (how many people actually use ABHA?). Synthetic data is sufficient to demonstrate the mechanism and appropriate given the 2-month scope and the sensitivity of real migrant worker health data.

Real-world validation using aggregate, anonymized administrative data (e.g. ABDM public dashboard indicators, Kerala Migrant Welfare Fund statistics) is a planned extension, not part of this initial prototype.
